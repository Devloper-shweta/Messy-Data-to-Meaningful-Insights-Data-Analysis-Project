# 📊 customer shopping Data Analysis using Pandas, NumPy & Matplotlib

## 🚀 Project Overview
This project focuses on analyzing **messy real-world sales data** and converting it into meaningful insights using Python libraries like Pandas, NumPy, and Matplotlib.

The dataset contains inconsistencies such as missing values, incorrect formats, and noisy data, which were cleaned and processed before analysis.

---

## 🛠️ Tools & Technologies
- Python 🐍
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

---

## 📂 Dataset
- Messy customer shopping dataset (with missing values, inconsistent date formats, etc.)
- Cleaned and processed using data preprocessing techniques

---

## 🔧 Key Steps Performed

### 1. Data Cleaning
- Handled missing values
- Fixed inconsistent column formats
- Converted date column into proper datetime format
- Removed invalid or duplicate records

### 2. Data Analysis
- Sales trend analysis over time
- Category-wise distribution
- Region-wise sales comparison

### 3. Data Visualization
- 📊 Bar Chart → Sales by Region  
- 🥧 Pie Chart → Category Distribution  
- 📈 Line Chart → Sales Over Time
